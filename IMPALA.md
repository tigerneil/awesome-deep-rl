# IMPALA: Scalable Distributed Deep-RL with Importance Weighted Actor-Learner Architectures

First public date: 2018-02-05. Conference venue: ICML 2018.

Authors: Lasse Espeholt, Hubert Soyer, Remi Munos, Karen Simonyan, Volodymyr Mnih, Tom Ward, Yotam Doron, Vlad Firoiu, Tim Harley, Iain Dunning, Shane Legg, Koray Kavukcuoglu.

## Method summary

Whereas [A3C](A3C.md) communicates parameter gradients across workers, **IMPALA** decouples trajectory collection on hundreds of CPU actors from centralized GPU minibatch learning. Because actor policies $\mu$ lag behind the learner policy $\pi_\theta$ by several updates, IMPALA introduces **V-trace**, an off-policy multi-step actor-critic correction with truncated importance weights that guarantees convergence to a well-defined fixed point without exploding variance.

## Mathematical formulation

Given a trajectory $(s_t, a_t, r_t)_{t=s}^{s+n}$ generated by behavior policy $\mu$, let $\rho_t = \min\!\big(\bar{\rho}, \frac{\pi_\theta(a_t \mid s_t)}{\mu(a_t \mid s_t)}\big)$ and $c_t = \min\!\big(\bar{c}, \frac{\pi_\theta(a_t \mid s_t)}{\mu(a_t \mid s_t)}\big)$ be truncated importance ratios ($\bar{\rho} \ge \bar{c}$). The $n$-step **V-trace** target $v_s$ for state $s_s$ is defined recursively as:

$$
v_s = V_\phi(s_s) + \sum_{t=s}^{s+n-1} \gamma^{t-s} \left(\prod_{i=s}^{t-1} c_i\right) \delta_t^V, \qquad \delta_t^V = \rho_t\big(r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)\big)
$$

Here $\rho_t$ defines the fixed point $V^{\pi_{\bar{\rho}}}$ toward which evaluation converges, while trace coefficients $c_i$ control contraction speed. The policy update uses $\rho_s \nabla_\theta \log \pi_\theta(a_s \mid s_s)\big(r_s + \gamma v_{s+1} - V_\phi(s_s)\big)$.
